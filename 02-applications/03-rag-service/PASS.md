# Stage 03 过关题作答

## 1. 什么时候不该上 RAG？

- 问题答案不在可检索语料里（硬上只会「一本正经胡说」）
- 纯创意/开放生成，不需要外部事实
- 强实时且库未同步（库存、行情）——除非检索链路本身实时且权限正确
- 延迟/成本预算极紧，而模型参数里已稳定具备该知识

此时应直接答、拒答，或走工具/API，而不是假装检索。

## 2. 引用丢失时如何降级？

本课策略：检索分数低于阈值则 **不调用生成胡编**，直接返回「未找到足够依据」。  
若生成了但未带 `[chunk_id]`，视为不合格输出，应重试一次并收紧 prompt，仍失败则降级为「依据不足」。  
生产上还可：要求结构化 JSON `{answer, citations[]}`，缺 citation 就拦截上线。
