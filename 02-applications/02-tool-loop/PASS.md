# Stage 02 过关题作答

## 1. 工具超时你会怎么重试？

对 `TimeoutError` / `ConnectionError`：工具层内指数退避重试（0.2s 起，上限 2s），最多 3 次；每次重试打日志。耗尽后把 `ERROR exhausted` 回灌模型，由模型降级叙述，而不是进程崩溃。

## 2. 哪些错误不该重试？

- 参数非法 / JSON 坏掉  
- 未知工具名  
- 业务校验失败（如计算器表达式不合法）  

这类重试只会浪费配额，应立刻 `non_retryable` 返回。

## 3. 记忆是会话级还是用户级？

本阶段是 **会话级（session）**：`messages` 只存在于单次 `run_agent` 调用。跨请求/跨用户的长期记忆需要外部存储（DB/向量记忆），未在本阶段实现。
