## 阶段详情与过关题

### ① LLM API / 工程地基

- **目标**：稳定调用 OpenAI 兼容中转站；密钥不进仓库；会看 token/延迟。  
- **学习**：Python venv、`openai` SDK、FastAPI 最小封装、结构化输出入门。  
- **交付**：`curriculum/stage-01/` 可运行服务 + README（含中转站 `base_url` 配置说明，不含密钥）。  
- **过关题**：为什么用环境变量而不是写死 Key？中转站和官方 API 在客户端配置上差什么？

### ② 单 Agent（工具 + 记忆 + 重试）

- **目标**：手写 Agent Loop；工具失败可重试；短期记忆可讲清边界。  
- **学习**：Function Calling、max_steps、结束条件、指数退避/降级。  
- **交付**：可演示的任务 Agent + 「失败重试」设计说明。  
- **过关题**：工具超时你会怎么重试？哪些错误不该重试？记忆是会话级还是用户级？

### ③ 生产向 RAG

- **目标**：切分 → 向量检索 →（可选）重排 → 带引用回答。  
- **学习**：Embedding、混合检索直觉、幻觉与引用。  
- **交付**：领域知识库 Demo + recall/命中笔记。  
- **过关题**：什么时候不该上 RAG？引用丢失时如何降级？

### ④ LangGraph / Multi-Agent + HITL

- **目标**：用状态机编排，而不是「一串 prompt」。  
- **学习**：State、节点、条件边、检查点、人机回环。  
- **交付**：至少一条可中断审批的图工作流。  
- **过关题（深挖必过）**：  
  1. 状态机里「状态」存了什么、为什么要持久化检查点？  
  2. 人机回环卡在哪一节点、恢复时如何避免重复副作用？  
  3. 什么场景该拆 Multi-Agent，什么场景单 Agent 就够？

### ⑤ MCP + 系统集成（Java 叙事）

- **目标**：工具协议化；业务权限在网关，不在 Prompt。  
- **学习**：MCP tool schema、鉴权边界；**Spring Boot 做业务 API / 鉴权网关**，Python Agent 调过来。  
- **交付**：MCP Server（知识或业务工具）+ 简易 Spring Boot 网关（登录/鉴权 stub）+ Agent 客户端。  
- **过关题（深挖必过）**：  
  1. MCP 的 tool schema 怎么设计才不容易被模型乱填参？  
  2. 鉴权边界画在 MCP、网关还是工具内部？各有什么坑？  
  3. 什么时候该上 MCP，什么时候自己写 tool 更合适？

### ⑥ 评测 / Tracing / 部署

- **目标**：效果可复现、问题可定位、服务可部署。  
- **学习**：黄金集、成功率/延迟/成本、Trace span、Docker。  
- **交付**：`eval` 报告 + 示例 Trace + `Dockerfile`。  
- **过关题（深挖必过）**：  
  1. 你的任务集怎么防「刷分」？  
  2. 成功率 / 延迟 / 成本如何一起看、如何做发布门禁？  
  3. 线上一次失败，你从 Trace 的哪几步开始查？

## 作品集：企业知识助手 Agent

端到端能力：

1. 用户经鉴权访问（阶段⑤网关）  
2. 按权限检索知识 / 调工具（隔离）  
3. 工具失败可重试与降级  
4. 回答带引用；全程可 Trace  
5. 附一份黄金集评测摘要（成功率 / 延迟 / 成本）

演示时默认会被追问阶段④⑤⑥的过关题。
